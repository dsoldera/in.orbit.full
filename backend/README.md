# IN ORBIT Backend

To start the application locally, first start the Docker with:
- `docker compose up -d`

Then, to create/update the database run:
- `npm run seed`

Then finally run the backend app:
- `npm run dev`

To run the Drizzle Studio run:
- `npx drizzle-kit studio`
